# Feature map

Where each feature's code and tests live. A path here that does not exist is a bug in this file.

The Tests column names files; the tests are in the `#[cfg(test)] mod tests` at the end of each. The commands under "Run only this feature" filter by test-name prefix.

| Feature | Screen / entry point | Logic | Tests | Run only this feature |
|---|---|---|---|---|
| Choosing the daemon (`DOCKER_HOST`, context, TLS, rootless) | `app/src/ui/pages.rs` (Settings), `app/src/ui/mod.rs` (connection button) | `crates/engine/src/target.rs`, `app/src/config.rs` | `crates/engine/src/target.rs`, `app/src/config.rs` | `cargo test -p engine --lib target::` |
| Connect, reconnect and state updates | `app/src/main.rs` | `app/src/state.rs`, `app/src/backend.rs`, `crates/engine/src/error.rs` | `app/src/state.rs`, `crates/engine/src/error.rs` | `cargo test -p docker-stack state::`, `cargo test -p engine --lib error::` |
| Starting the daemon | `app/src/ui/model.rs` (connection banner) | `crates/engine/src/daemon.rs`, `start_daemon` in `app/src/commands.rs` | `crates/engine/src/daemon.rs` | `cargo test -p engine --lib daemon::` |
